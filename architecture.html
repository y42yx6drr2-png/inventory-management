REST API Endpoints

  • GET /api/inventory - Retrieve inventory items (filters: warehouse, category)
  • GET /api/inventory/{id} - Get specific inventory item
  • GET /api/orders - Retrieve orders (filters: warehouse, category, status, month)
  • GET /api/orders/{id} - Get specific order details
  • GET /api/demand - Get demand forecasts
  • GET /api/backlog - Get backlog items
  • GET /api/dashboard/summary - Get dashboard summary metrics
  • GET /api/spending/* - Various spending endpoints (summary, monthly, categories, transactions)

Data Sources

JSON files loaded at server startup and kept in memory:

server/data/inventory.json - Product inventory data
server/data/orders.json - Customer orders
server/data/demand_forecasts.json - Demand predictions
server/data/backlog_items.json - Delayed orders
server/data/spending.json - Spending analytics
server/data/transactions.json - Transaction history
server/data/purchase_orders.json - Purchase order records

Key Architectural Features

Filter System

Unified filtering across 4 dimensions:

  • Time Period (Month/Quarter)
  • Warehouse Location
  • Product Category
  • Order Status

Reactive UI

Vue 3 Composition API patterns:

  • Raw data in refs
  • Derived data in computed properties
  • Automatic reactivity
  • Component composition

Type Safety

Full validation with Pydantic:

  • Request validation
  • Response schemas
  • Auto-generated API docs
  • Runtime type checking
